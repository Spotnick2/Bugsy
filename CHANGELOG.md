# Changelog

## Unreleased

- A new window: each problem listed by the addon that appears involved, its count and when it was
  last seen; search; This session and History; a clear "monitoring" status; Bugsy's hat.
- Out-of-date addons are marked after a patch day, with a suggestion to turn them off until
  they're updated (Bugsy never turns anything off itself).
- **Copy for a bug report**: the diagnostics ready to paste, in Markdown for a GitHub issue or as
  a short text for a CurseForge comment.
- A guided report in three steps (Describe, Review, Copy & report), with a searchable addon picker.
- Two looks: WoW Forever and Pearl Glass (with a Glass addon loaded; follows Glass UI's look).
- A minimap button (left-click: the window, right-click: the settings; `/bugsy minimap off`
  hides it), and Bugsy's icon in the addon list.
- The report form: Tab moves to the next answer, Shift+Tab to the previous.
- Bugsy's page in Options > AddOns (`/bugsy options`): every setting, the capture status, and an
  About page with the commands.
- An alert sound when a new problem is caught (`/bugsy sound on|off`), one of six
  (`/bugsy sound 1-6`).
- First vertical slice: native capture with budgets and secret-safe markers, coexistence with
  another error collector, problems with grouping signatures, the window, the report flow,
  Markdown and JSON export.
